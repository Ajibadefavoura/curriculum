About PlaqueScope

PlaqueScope is a modern, web-based virus plaque counter inspired by Viridot, designed for faster, easier, and more accurate plaque analysis.

Key Improvements over Viridot

Modern Web UI

Drag-and-drop interface with real-time preview. No R installation required.

Advanced Image Processing

Adaptive thresholding, watershed segmentation, multi-color-space analysis, and morphological refinement.

Per-Plaque Confidence

Each detected plaque gets a confidence score based on circularity and size metrics.

Processing Pipeline Viewer

See every step of the image processing pipeline to understand and optimize detection.

Multiple Plate Formats

Supports 6-, 12-, 24-, and 96-well plate formats with automatic well detection.

Flexible Titer Estimation

2PL, 3PL, and 4PL logistic regression with confidence intervals and interactive dose-response curves.

Zero Installation

Runs in any web browser. No R, no BiocManager, no EBImage setup headaches.

Export Everywhere

Export results as CSV, JSON, or annotated images with a single click.

Technology

Built with Python, Flask, OpenCV, scikit-image, and SciPy. The frontend uses vanilla JavaScript with a modern CSS design system.
